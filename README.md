# alexxpowered.top

这个仓库发布 alexxpowered.top 下的静态页面。足迹地图的源仓库为 [Alexx-Powered/footprint-map](https://github.com/Alexx-Powered/footprint-map)。

更新足迹地图时，从源仓库的正式版本复制 index.html 到 footprint-map/index.html，再提交发布。

冷却层纹演示发布在 [layer-time-smoother/](https://alexxpowered.top/layer-time-smoother/)。从[源项目的发布工作流](https://github.com/Alexx-Powered/layer-time-smoother/actions/workflows/demo-pages.yml)下载对应版本的 `layer-time-smoother-static` 文件包，更新同名子目录后提交到本仓库。
